# Samar Devraj portfolio

A static, multi-page portfolio for GitHub Pages.

Run locally from this folder:

```sh
python3 -m http.server 8731
```

Open http://localhost:8731/. The site uses plain HTML, shared `styles.css` and `script.js`, and web-sized images in `assets/`.

GitHub Pages publishes the `main` branch from the repository root. `.nojekyll` keeps the static files intact. Hero design proposals are maintained separately and are not part of this website.

The contact form submits directly to Web3Forms using the access key configured in `contact.html`. Confirm receipt of a test message before relying on delivery.
